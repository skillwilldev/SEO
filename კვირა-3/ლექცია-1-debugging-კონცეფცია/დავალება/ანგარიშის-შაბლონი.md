## 2. დეტალური აღწერა

### ბაგი #1

**სიმპტომი:** "ბოლო დამატებიდან" მთვლელი წამში 2-ით იზრდება და unmount-ის მერეც აგრძელებს ტიკტიკს

**როგორ ვიპოვე (ნაბიჯები):** გავხსენი Console, წავიკითხე სიმპტომი და შევამოწמებდი StreakBadge კომპონენტს

**მიზეზი:** useEffect-ში setInterval-ს არ ჰქონდა დაბრუნებული cleanup ფუნქცია (clearInterval)

**გამოსწორება (before / after):**

```jsx
// before
useEffect(() => {
  const interval = setInterval(() => setTimeSinceLastAdd(prev => prev + 1), 1000)
}, [])
// after
useEffect(() => {
  const interval = setInterval(() => setTimeSinceLastAdd(prev => prev + 1), 1000)
  return () => clearInterval(interval)
}, [])
```

### ბაგი #2

**სიმპტომი:** checkbox-ზე დაწკაპუნებაზე ჩვევა შესრულებულად არ აღინიშნება.

**როგორ ვიპოვე (ნაბიჯები):** გამოვიყენე React DevTools და ვნახე, რომ habits state არ იცვლებოდა

**მიზეზი:** მოხდა სთეითის პირდაპირი მუტაცია (habit.doneToday = ...) და რეფერენსი იგივე დარჩა

**გამოსწორება (before / after):**

```jsx
// before
const habit = habits.find(h => h.id === id)
habit.doneToday = !habit.doneToday
setHabits(habits)
// after
setHabits(habits.map(h => h.id === id ? { ...h, doneToday: !h.doneToday } : h))
```

### ბაგი #3

**სიმპტომი:** ფილტრის ღილაკები სიას არ ცვლიან

**როგორ ვიპოვე (ნაბიჯები):** შევამოწმე ფილტრაციის ლოგიკა HabitTracker.jsx ფაილში

**მიზეზი:** ფილტრის ცვლილება არ იწვევდა სიის დინამიკურ გადაანგარიშებას

**გამოსწორება (before / after):**

```jsx
// before (გატეხილი useEffect/state მიდგომა)
// after
const visibleHabits = habits.filter(habit => {
  if (filter === 'active') return !habit.doneToday
  if (filter === 'done') return habit.doneToday
  return true
})
```

### ბაგი #4

**სიმპტომი:** "5 წამში წაშლა" შლის ახალ ჩვევებს

**როგორ ვიპოვე (ნაბიჯები):** დავსვი breakpoint და დავაკვირდი Scope პანელს setTimeout-ის შიგნით

**მიზეზი:** Stale Closure — setTimeout იმახსოვრებდა ძველ habits მასივს

**გამოსწორება (before / after):**

```jsx
// before
setTimeout(() => setHabits(habits.filter(h => h.id !== id)), 5000)
// after
setTimeout(() => setHabits(prev => prev.filter(h => h.id !== id)), 5000)
```

### ბაგი #5

**სიმპტომი:** წაშლის შემდეგ შენიშვნები სხვა ჩვევებზე გადადის (ინაცვლებს)

**როგორ ვიპოვე (ნაბიჯები):** გადავამოწმე TaskList კომპონენტი

**მიზეზი:** key-ად გამოყენებული იყო მასივის ინდექსი (key={index}), რაც არასტაბილურია

**გამოსწორება (before / after):**

```jsx
// before
{habits.map((habit, index) => <HabitCard key={index} ... />)}
// after
{habits.map((habit) => <HabitCard key={habit.id} ... />)}
```

### ბაგი #6

**სიმპტომი:** სწრაფად დამატებული ჩვევები იკარგება

**როგორ ვიპოვე (ნაბიჯები):** ვცადე ентერის სწრაფად მრავალჯერ დაკლიკება და გამოვიყენე breakpoint-ი

**მიზეზი:** Async Race Condition — რამოდენიმე ასინქრონული თაიმერი ერთდროულად ცდილობდა ძველ სთეითზე დაყრდნობით დამატებას

**გამოსწორება (before / after):**

```jsx
// before
setTimeout(() => setHabits([...habits, newHabit]), 150)
// after
setTimeout(() => setHabits(prev => [...prev, newHabit]), 150)
```

3. **როგორ შეიძლებოდა ამ 6 ბაგიდან 3-ის პრევენცია დაწერის ეტაპზევე?** (ESLint წესები, code review, ტესტები)
