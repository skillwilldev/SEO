## 2. ბაგი #1 — ქვეჯამი

**Scope-ის დაკვირვება:**

| iteration | `i` | `items.length` | `subtotal` |
|---|---|---|---|
| 1 | 1 | 1 | 0 |
| 2 | - | - | - |

**მიზეზი:** ციკლი იწყებოდა `let i = 1`-ით, ამიტომ ერთადერთი ელემენტი (`items[0]`) სრულად გამოტოვებული იქნა ჯამის დათვლისას.

**გამოსწორება:**

```js
// before
for (let i = 1; i < items.length; i++) {
  subtotal += items[i].price * items[i].quantity;
}

// after
for (let i = 0; i < items.length; i++) {
  subtotal += items[i].price * items[i].quantity;
}
```
